Lista de definiciones

URL
Es la dirección que identifica un recurso en Internet, como una página web, una imagen o un archivo.
HTTP
Es el protocolo que permite la comunicación entre un navegador web y un servidor para solicitar y transmitir recursos de una página web.
TCP/IP
Es el conjunto de protocolos que permite la comunicación y el intercambio de datos entre dispositivos conectados a Internet.
Internet
Es una red mundial de redes informáticas interconectadas que permite la comunicación y el intercambio de información entre dispositivos.
W3C
Es el World Wide Web Consortium, una organización que desarrolla estándares y recomendaciones para garantizar el funcionamiento y la evolución de la Web.
HTML
Es el lenguaje de marcado utilizado para estructurar y organizar el contenido de las páginas web.
